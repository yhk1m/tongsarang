# 2026년 시행 기출 추가 + 통합사회 학년 구분 (설계)

작성일: 2026-08-17

## 목적

1. 2026년에 시행된 사회탐구 기출문제를 통사랑에 추가한다.
2. 올해 신설된 고2 통합사회 문항을 고1 문항과 같은 통합사회 탭에 넣되, 학년으로 구분·필터할 수 있게 한다.
3. 정답률·난이도는 메가스터디에서 가져온다.

## 배경: 기존 연도 표기 규칙

세계사 데이터의 답·정답률을 메가스터디 examSeq와 대조해 확정한 규칙이다.

- **모평(6월·9월)·수능** → `학년도` 표기. 예: `2026 6모` = 2025년 6월 시행
- **학평(3·4·5·7·10월)** → `시행연도` 표기. 예: `2025 7월학평` = 2025년 7월 시행

이번 추가분도 이 규칙을 그대로 따른다. 결과적으로 2026.06.04 모평만 `2027`로 들어간다.

분류 어휘는 과목별로 다르다.

- 한국지리: `3월학평 4월학평 5월학평 7월학평 10월학평 6모 9모 수능`
- 그 외 전 과목: `3월 4월 5월 6월 7월 9월 10월 11월 수능`

## 스키마 변경

### `학년` 필드 신설

- 값: `'고1'` / `'고2'`. 통합사회 전용이며 다른 과목은 `''`.
- 기존 통합사회 655행에 `학년='고1'`을 일괄 부여한다. 그래야 필터가 과거 데이터에도 동작한다.

### 이미지 코드

- 통합사회 고1 = `iss` (기존 파일명 그대로 유지)
- 통합사회 고2 = `iss2`

### 행 키

지금 `${학년도}_${분류}_${번호}` 키가 `EditStore.js`와 `LinkerStore.js`에 중복 구현돼 있다. 고1·고2가 모두 `2026 3월 1번`이 되어 충돌하므로 키를 확장해야 한다.

`src/core/questionKey.js`를 새로 만들어 한 곳으로 모으고, **학년이 `고2`일 때만** 세그먼트를 추가한다.

```
questionKey(item) = 학년 === '고2'
  ? `${학년도}_${분류}_고2_${번호}`
  : `${학년도}_${분류}_${번호}`
```

모든 통합사회 행에 학년 세그먼트를 넣는 대안은 `public/data/default_mappings.json`의 기존 통합사회 성취기준 매핑을 전부 깨뜨리므로 택하지 않는다.

## 수집 파이프라인

### EBSi 문제 PDF — `scripts/fetch_ebsi_2026.py` (신규)

EBSi API 규격이 바뀌어 기존 `download_and_crop_history.py`는 동작하지 않는다.

- 엔드포인트: `POST https://www.ebsi.co.kr/ebs/xip/xipc/previousPaperListAjax.ajax`
- 파라미터: `targetCd, yearList, monthList, arOrd, subjIdList, sort, currentPage`
  - 구 규격(`beginYear/endYear/subjList`)은 결과 0건을 반환한다
- `targetCd`: 고3 `D300`, 고1 `D100`, 고2 `D200`
- `arOrd`: 사회탐구·통합사회 `5`, 한국사 `4`
- `subjIdList` (D300): 생윤 `63002`, 윤사 `63003`, 한지 `141`, 세지 `142`, 동아사 `63001`, 세계사 `146`, 정법 `140112`, 경제 `66002`, 사문 `66001`, 한국사 `63004`
- `subjIdList`: 통합사회 고1 `140072`(D100), 고2 `140220`(D200)
- PDF: 목록의 `goDownLoadP('/경로.pdf', ...)` → `https://wdown.ebsi.co.kr/W61001/01exam` + 경로
- 저장: `모의고사/{과목}/작업완료/{학년도}_{MM}_{code}.pdf`

### 문항 크롭

기존 `fix_bottom_cutoff.py`의 `crop_and_save()`를 재사용해 PNG로 자르고, `public/images/{과목}/{학년도}_{MM}_{code}_{NN}.jpg`로 변환·복사한다.

시험지에 따라 문항 번호 글꼴 크기가 섞여 있어(예: 2026년 7월 사회·문화는 8·15번만 14.0pt, 나머지는 13.4pt) 기본 허용 오차 `SIZE_TOLERANCE = 0.5`로는 일부 문항이 검출되지 않는다. `fetch_ebsi_2026.py`가 예상 문항 수에 못 미치면 허용 오차를 0.8 → 1.2로 넓혀가며 다시 자른다. 원본 `fix_bottom_cutoff.py`의 기본값은 건드리지 않는다 — 기존 12,000여 이미지가 그 값으로 추출됐기 때문이다.

### 답·배점·난이도·정답률 — `scripts/crawl_megastudy_2026.cjs` (신규)

- 엔드포인트: `POST https://www.megastudy.net/Entinfo/correctRate/main_rate_ax.asp` (EUC-KR)
- `examSeq`: 고3 3월 `352`, 5월 `353`, 6월 `356`, 7월 `357` / 고1 3월 `350`, 6월 `354` / 고2 3월 `351`, 6월 `355`
- `tabNo`: 사회탐구·통합사회 `5`, 한국사 `4`
- `selSubCd`: 생윤 `4117`, 윤사 `4118`, 한지 `4102`, 세지 `4103`, 동아사 `4116`, 세계사 `4107`, 경제 `4110`, 정법 `4121`, 사문 `4111`
- 응답의 `<td class="two">`를 10칸 단위로 끊으면 `번호, 정답, 난이도, 배점, 정답률, 선지1~5`

### 발문·문항내용

기존 `scripts/ocr_subjects.cjs`(tesseract)를 재사용한다. 통합사회 고2 이미지 코드 분기만 추가한다.

### 대단원 — `scripts/classify_chapters_2026.cjs` (신규)

기존 분류 스크립트(`classify_all.cjs` 등)는 한국지리 전용 키워드 규칙이라 11개 과목으로 확장하려면 규칙을 새로 다 써야 한다. 대신 **이미 분류된 12,800여 문항을 학습 데이터로 삼아** 분류한다.

- 발문 + 문항내용의 문자 바이그램 TF-IDF 코사인 유사도
- 같은 과목에서 가장 비슷한 상위 7개 문항의 유사도 가중 투표로 대단원 결정
- 중단원은 1순위 이웃의 대단원이 투표 결과와 같을 때만 따라 쓴다
- 확신도(1등 득표 비중)가 0.45 미만이면 검수 목록으로 출력

성취기준은 수동 연결 영역이라 비워둔다.
